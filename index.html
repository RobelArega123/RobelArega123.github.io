About Me

I’m a senior Information Systems student at Seattle Pacific University, based in Seattle, and I’m set to graduate in June 2027. I’m interested in the place where technology and business meet: building software that solves a real problem and understanding the people and organizations who will use it.

My coursework has covered database systems, software engineering, and networked computing, and this year I’m working with a team of five on a Senior Capstone project, AthleteGuard, using Agile Scrum with sprint planning, daily standups, and demos. That experience has taught me how to turn a rough idea into user stories, a clear feature list, and a plan a team can build together.

After graduation I’m aiming for a software engineering role, and I also have business ambitions of my own. I learn best by building things, which is why this portfolio is full of working projects.

AthleteGuard

Team Senior Capstone, team of five

What it is: A sports performance and injury prevention platform. Athletes log workouts and daily wellness check-ins (sleep, fatigue, soreness), the app flags potential injury-risk indicators, and coaches see which athletes need attention.

My role: Backend Developer: API, database, authentication, and deployment.

Transactions API

Individual Class project, Netcentric Computing

A REST API for storing credit card transactions, built with Node.js, Express, and MongoDB Atlas and deployed on Heroku. It uses an append-only design: transactions are never edited or deleted, and corrections are made with amendment transactions. It supports filtering by date, date range, and card nickname, and includes a seed script, Docker setup, and full documentation.

Live app · GitHub

Sneakers API

Individual Class project, Node.js, Express, MongoDB, Docker Dev Container

A REST API for managing sneaker data with full CRUD (GET, POST, PUT, PATCH, DELETE), dynamic filtering by brand, price range, and size, a health-check route, and a seed script that loads 20 sample records. My README explains concepts such as environment variables and the difference between PUT and PATCH.
